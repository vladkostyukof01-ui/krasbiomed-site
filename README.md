# ООО «КрасБиоМед-Иммуно» — сайт

Редизайн сайта krasbiomed.ru (Красноярск) на Node.js + Express + SQLite. Компания —
поставщик медицинских иммунобиологических препаратов (вакцины, иммуноглобулины,
бактериофаги, аллергены, сыворотки) с 2005 года: собственный прививочный кабинет для
частных пациентов + оптовые поставки аптечным сетям и учреждениям с соблюдением
холодовой цепи.

**Важная техническая находка при сборе контента**: на момент редизайна оригинальный
сайт krasbiomed.ru был частично взломан — прямые URL разделов «Услуги», «Информация»,
«Цены», «Реквизиты», «Документы», «Сертификаты» отдавали постороннюю индонезийскую
гэмблинг-рекламу вместо настоящего контента (WordPress REST API при этом продолжал
отдавать подлинные данные). Весь контент этого сайта восстановлен из WP REST API
(`/wp-json/wp/v2/pages`), а не из скомпрометированных HTML-страниц — то есть является
подлинным содержимым владельца, а не поддельным.

## Стек

- Express (сервер, роуты, API)
- better-sqlite3 (БД, режим WAL)
- express-session + bcryptjs (авторизация админа)
- express-rate-limit (защита от подбора пароля)
- helmet (security headers, CSP)

## Функциональность

- **Форма «Оставить заявку»** (`/api/leads`) — тип обращения (вакцинация в кабинете,
  серопрофилактика клеща, выездная вакцинация, оптовая поставка, другое), поле
  организации для оптовых заявок, согласие на обработку персональных данных (152-ФЗ).
- **Прейскурант с поиском** (`/vakciny`) — аккордеон по 15 категориям вакцин с быстрым
  поиском по названию или производителю.
- **Админ-панель** — заявки, услуги (текст карточек), прейскурант (CRUD), документы
  (просмотр), настройки сайта редактируются без правки кода.

## Дизайн-концепция: «Холодовая цепь»

Вакцины и иммунобиологические препараты должны храниться и перевозиться в строгом
температурном диапазоне +2…+8°C на всём пути от производителя до пациента — этот
термин («холодовая цепь») использует сама компания на исходном сайте. Вместо клише
ДНК-спирали или пробирки выбран специфичный для дистрибьютора биопрепаратов мотив:
вертикальный температурный индикатор с подсвеченной безопасной зоной (как на
термоиндикаторах на упаковках вакцин) и цепочка контрольных точек (производитель →
термоконтейнер → склад → доставка → пациент), соединённых пунктиром.

Палитра: морозно-белый `#EFF5F7` (фон), глубокий сине-угольный `#10222C` (текст/шапка/
подвал), приглушённый холодный сине-серый `#4A7A94` (акцент, холоднее и серее бирюзы
Аква96), тёплый янтарь `#E8A33D` (CTA — цвет предупреждающей наклейки термоконтейнера),
редкий алый `#C1443A` только для дисклеймера. Шрифты — 'Fraunces' (контрастный serif
для заголовков), 'Inter' (текст), 'JetBrains Mono' (температуры, номера лицензий, цены).

Мотив и палитра не пересекаются с уже занятыми у других сайтов очереди: тил/чернильный
(Аква96), сеть линий «Меридиан» (Безлекарственная медицина), гониометр графит/кость/
коралл (Планета Здоровья), дуга рассвета графит/пергамент/хвоя/свеча (Вечность), paper/
dossier (Монолит), индиго/янтарь-тикер (Бегучка).

## Локальный запуск

```
npm install
npm run seed    # создаёт БД, наполняет реальными данными, создаёт админа
npm start       # http://localhost:3506
```

Админ-панель: http://localhost:3506/admin — логин/пароль по умолчанию `admin` /
`krasbiomed2026` (задаётся в `server/seed.js` через `ADMIN_USERNAME`/`ADMIN_PASSWORD` из
окружения процесса — не из `.env`, так как `seed.js` не подключает dotenv; обязательно
смените пароль через админ-панель после первого входа).

## Перед деплоем — обязательно

1. Скопировать `.env.example` в `.env`, задать реальный `SESSION_SECRET` (длинная
   случайная строка).
2. Сменить пароль администратора через админ-панель.
3. ✅ Canonical-теги уже указывают на `https://krasbiomed-site.onrender.com` (включая
   динамический `/uslugi/:slug` в `server/index.js`). Если сайт переедет на свой домен —
   заменить везде на новый адрес.
4. Учесть находку про взлом оригинального сайта — прежде чем клиент откажется от
   переезда на новый сайт, стоит показать ему, что происходит на текущих URL разделов.

## Деплой на PaaS (Render и подобные)

1. Создать новый Web Service, подключить репозиторий.
2. Build command: `npm install && npm run seed` (seed идемпотентен — безопасно
   запускать при каждом деплое, данные не задвоятся).
3. Start command: `npm start`.
4. Задать переменные окружения (`SESSION_SECRET`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`,
   `NODE_ENV=production`) в панели хостинга — см. `render.yaml`.
5. **Важно**: SQLite-файл должен жить на постоянном (не эфемерном) диске — на части
   бесплатных тарифов PaaS файловая система сбрасывается при каждом деплое.

## Резервное копирование

`npm run backup` — создаёт снапшот БД в `data/backups/` (хранит последние 14 копий).
Поставьте эту команду в cron на хостинге (например, раз в сутки).

Восстановление: остановить сервер → удалить `*.db-wal`/`*.db-shm` → скопировать нужный
файл из `data/backups/` поверх `data/krasbiomed.db` → запустить сервер заново.
